Column Chart

Column charts are best for representing categorical data, or data which can be split into groups, over time. Humans are very good at using height to tell objects apart from each other, and column charts make great use of this by having taller bars mean larger values for the category. Compared to bar charts, column charts project vertically and not horizontally.
